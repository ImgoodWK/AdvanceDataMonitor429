TeXTech WebAE optional UI bundle / WebAE 可选前端资源包
========================================================

English
-------
1. Install the matching TeXTech main jar in mods/.
2. Extract this ZIP into the Minecraft instance root (the directory containing
   config/ and mods/). Keep the included TeXTech/WebAE/ui/ directory structure.
3. Enable [webConsole] enabled=true and restart the game/server.
4. Open http://127.0.0.1:8090 by default.

The main mod jar intentionally does not contain these browser assets. Players
and servers that do not use WebAE do not need this ZIP.

简体中文
--------
1. 把同版本 TeXTech 主 JAR 放入 mods/。
2. 将本 ZIP 解压到 Minecraft 实例根目录（与 config/、mods/ 同级），保留
   TeXTech/WebAE/ui/ 目录结构。
3. 设置 [webConsole] enabled=true，然后重启游戏或服务端。
4. 默认访问 http://127.0.0.1:8090。

主模组 JAR 有意不包含这些浏览器静态资源；不使用 WebAE 的玩家和服务端
无需下载本 ZIP。
