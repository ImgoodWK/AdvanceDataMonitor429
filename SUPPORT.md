# TeXTech support

Use the route that matches the request so reproducible defects remain easy to
triage.

| Need | Start here |
| --- | --- |
| Install, items, or in-game usage | [Player guide](docs/en/player/player-guide.md) |
| WebAE setup, binding, or tokens | [WebAE user guide](docs/en/webae/user-guide.md) |
| Build, API, packets, or frontend development | [Developer documentation](docs/en/developer/technical-documentation.md) |
| AI or voice integration | [AI assistant development guide](docs/en/ai-assistant/development-guide.md) |
| Reproducible defect | [Bug report form](https://github.com/ImgoodWK/TeXTech-GTNH/issues/new?template=bug_report.yml) |
| Focused feature proposal | [Feature request form](https://github.com/ImgoodWK/TeXTech-GTNH/issues/new?template=feature_request.yml) |
| Usage question, idea, or showcase | [GitHub Discussions](https://github.com/ImgoodWK/TeXTech-GTNH/discussions) |
| Private security concern | [Security policy](SECURITY.md) |

When asking for help, include the TeXTech release or commit, Minecraft / Forge
/ GTNH versions, client or dedicated-server context, the smallest reproduction,
and sanitized configuration. Do not upload full world saves, credentials,
player UUIDs, private addresses, or unsanitized logs.

Chinese documentation starts at [`docs/zh/README.md`](docs/zh/README.md);
English documentation starts at [`docs/en/README.md`](docs/en/README.md).
