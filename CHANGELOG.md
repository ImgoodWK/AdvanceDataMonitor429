# Changelog

All notable public TeXTech release lines are summarized here. Detailed behavior remains documented under `docs/`, and Git tags/releases remain the authority for exact source snapshots and downloadable assets.

## [3.0.0-rc.1] - 2026-08-05

### Added

- Expanded Advance Data Monitor rendering with multiple chart/table widgets, threshold evaluation, render caching, and delta-oriented binding synchronization.
- Added WebAE CPU history and capacity planning, network-health diagnostics, versioned world-map snapshots/diffs, annotations, and hardened binary transfer boundaries.
- Added assistant operations briefings and expanded AstrBot/QQ companion, link-summary, dashboard, and image-gallery integration surfaces.
- Added a bilingual documentation portal, navigation-only Wiki source, professional TeXTech brand assets, public provenance records, and repository community files.

### Changed

- Reworked GUI theming, sparse atlas regions, viewport scaling, low-resolution layouts, and representative item textures.
- Standardized the public brand and repository identity as TeXTech / 铽丝科技 / `textech` at `ImgoodWK/TeXTech-GTNH`.
- Split release delivery into core JAR, optional voice JAR, WebAE ZIP, and sources JAR with checksums and attestations.
- Made official Gradle/plugin repositories the default; China mirrors require explicit `-Ptextech.useChinaMirrors=true` opt-in.

### RC notes

- This is a pre-release. `v2.0.0` remains the Latest stable release during the observation window.
- Full client, dedicated-server, optional voice, WebAE, and v2 world/config upgrade smoke tests are promotion gates for `v3.0.0`.
- Card Battle item delivery remains disabled until its allowlist and idempotent world-side ledger are complete.

## [2.0.0] - 2026-07-30

- Established the TeXTech 2.0 release line for GTNH `2.9.0-beta-2+`.
- Separated WebAE browser assets and the large offline voice model from the required core mod JAR.
- Expanded WebAE, AI/voice, planner, grapple, dimensional pocket, and documentation surfaces.

## [1.0.0] - 2026-06-25

- First tagged public release line.
- Delivered the original Advance Data Monitor foundation and the initial broader TeXTech gameplay/tooling set.
