## 0. 设计灵感与约束

### 0.1 三重命名语义

| 维度 | 含义 | 视觉落点 |
|------|------|----------|
| **铽（Terbium, Tb）** | 稀土元素；高效 **绿色荧光粉激活剂**（发光/显示）；**磁光存储 / 超磁致伸缩**（存储/精密） | 与模组「显示、监控、存储、AE 信息」呼应；可引绿光、磁光、周期表、原子轨道 |
| **tex（细度/排版）** | 纱线或纤维细度单位；编织/排版 | 与「编织数据」呼应；可引线、纱、织机、折线 |
| **TeX（Knuth 排版系统）** | 高质量、稳定、开源、ASCII 文本、学术出版；**字母全由折角构成** | 与「编织/排版数据」呼应；可引折角字形、ASCII/二进制纹理 |

### 0.2 品牌硬约束（生成时一律遵守）

- **配色**：深空底 `#0E1A30` / 侧栏蓝 `#122040` / 核心青 `#00FFFF` / 手册亮青 `#00E5FF` / 侧栏冰 `#C8E0FF`；7:2:1（深蓝黑 : 青辉 : 功能/传奇点缀）。
- **字标建议**：`TeX` 用核心青，`Tech` 用侧栏冰；底纹为 faint 六边形网格或二进制 0101 纹理（5–8%）。
- **Logo 规格**：256×256（icon）、512×512（高清）；中心 80% 圆形安全区；四角留 8px 暗边。
- **避免**：纯绿做主色、高饱和粉、扁平 Material Design 圆角、与 AE2/GT 冲突的塑料感。
- **风格后缀**：`GregTech New Horizons mod aesthetic, industrial sci-fi, deep navy blue and cyan glow color palette, volumetric lighting, dark background, high detail`。

## 1. 20 个概念

### 设计族 A — TeX 字标 / 折角字母形

#### A1 · 折角 TeX 字标
纯几何无衬线 `TeX` 三字母，所有笔画由 45°/90° 折角构成（致敬 TEX 折角字形）；`TeX` 核心青，`Tech` 侧栏冰；底纹 6% 六边形网格；深空底。极简、可缩放，最适合作 mcmod.info logoFile。

#### A2 · 数据线交叉 X
`TeX` 字标，`X` 由两根交叉的青色 AE2 数据线缆构成（末端带端口节点），`Te` 为折角实心字；深空底 + faint 二进制 0101 纹理。AE2 网络 × TeX 排版交叉。

#### A3 · 编织环 X
`TeX` 字标，`X` 替换为一个旋转的青色编织环，`Te` 折角字。tex=编织 + TeX 排版双关，一图两义。

#### A4 · 二进制折角 TeX
`TeX` 三字母由 0/1 比特位图拼成折角字形（像素感），青色比特浮于深空底；远看是字母、近看是数据。呼应 TeX「源文件为 ASCII 文本」。

#### A5 · 折线图 T 横梁
`T` 的横梁本身就是一条青色折线图（带数据点），竖梁为折角支柱，`eX` 跟随。监视器图表 × TeX 字母融合。

### 设计族 B — 监视器 + 编织环（品牌指南主概念）

#### B6 · 经典监视器编织环（指南主概念）
圆形安全区内简化高级数据监视器正面；屏幕显示青色折线图 + 中心编织环；深空蓝黑渐变底；淡淡六边形网格；四角编织环点缀；底部 faint `TeXTech` 字标。指南钦定方向，最稳。

#### B7 · 六边形网格监视器
监视器正面居中，背景为放大六边形蜂窝网格（5–8% 透明度），屏幕内折线图 + 编织环；偏 HUD 仪表盘风，适合手册封面。

#### B8 · 二进制流注入监视器
左侧 `0101` 数据流汇入监视器屏幕，屏幕内编织环把数据「织」成折线图；动态感强，直译 slogan「从数据洪流中编织现实」。

### 设计族 C — 铽元素 / 周期表 / 原子

#### C9 · 周期表 Tb 单元
周期表风格方格，内含 `Tb` + 原子序数 65，方格内嵌微型监视器+编织环，方格边缘青色辉光，深空底。铽元素 + 模组核心符号，化学辨识度高。

#### C10 · 绿色荧光 Tb
突出铽「绿色荧光粉激活剂」特性——`Tb` 字母发出明亮绿光，背景为暗监视器屏幕，屏幕内折线图被绿光照亮；绿光仅作点缀（≤10%），主色仍青/深蓝，不违品牌「避免纯绿主色」原则。

#### C11 · 原子轨道 T
原子轨道符号，核为 `Tb`，三条轨道电子排布勾勒出 `T` 字母轮廓，轨道青色辉光，深空底。铽的磁光/原子属性 × T 字母。

### 设计族 D — 编织 / 线 / 纱

#### D12 · 织机 TeX
织机/经纬线图案，青色数据线在深空底上交织出 `TeX` 字母（字母由线的交错形成，非实心）。编织 × 排版，最直白的 tex 双关。

#### D13 · 线轴 + 二进制流 T
青色线轴放出二进制 `0101` 线，线流构成 `T` 字母，线轴为金属质感（GT 工业风）。tex 细度单位 × 数据线。

#### D14 · 编织物 T 纹理
编织布纹肌理整体构成 `T` 字母，青色经线 + 侧栏冰纬线，深空底，布纹带细微二进制起伏。偏纹理感，差异化方向。

### 设计族 E — AE2 元件 / 存储

#### E15 · AE2 元件壳 + 编织环
AE2 存储元件外壳（带加速卡金手指暗示），中心为旋转编织环，青色辉光；元件轮廓同时暗示 `T`。数据编织元件（模组签名物品），与游戏内物品视觉一致。

#### E16 · ME 驱动器 T 剪影
ME 驱动器正面剪影，槽位青光排列成 `T` 字母，深空金属底。AE2 存储 × T 字母。

### 设计族 F — 徽章 / 徽标 / 盾形

#### F17 · 圆形外环徽章
圆形徽章，外环 `TeXTech · 铽丝科技` 文字 + 小编织环分隔符，内圆为监视器+折线图+编织环；深空底 + 青辉。完整品牌徽章，适合 GitHub avatar / 整合包图标（外环文字小尺寸不可读，需大图版本）。

#### F18 · 六边形徽章
六边形徽章，内含 `Tb` + 编织环 + 微型监视器三角构图，六边形呼应底纹网格。铽 + 编织 + 监视器三合一，几何统一，辨识度高。

#### F19 · 盾形 crest
盾形纹章，上为至高天圣裁剑（星蓝/紫黑），中为监视器+折线图，下为编织环；橙金（砂糖桔）+ 紫（织源）作 ≤10% 点缀。覆盖四大系统叙事柱，传奇感，适合 banner 不适合 icon。

### 设计族 G — 极简 / 单字母

#### G20 · 编织环 T 单字
极简 `T` 字母，横梁为编织环（环即横梁），竖梁为折角支柱；核心青 + 深空底，无任何附加纹理。TeX 折角 + 编织环 + T 字母三合一，最精炼，16px 仍清晰，最适合游戏内小图标。

## 3. 定稿结果

1. 选定 **B6 · 经典监视器编织环**：监视器代表 AE2 数据观察与 WebAE，连续编织环代表二进制线把数据重新编织为现实。
2. 图形使用 Codex 内置 OpenAI ImageGen 基于 B6 精修方向生成；文字没有交给生成模型，`TeXTech`、`铽丝科技` 与 Slogan 均在本地确定性排版。
3. 透明 Logo 采用纯色 chroma-key 背景生成，再在本地完成去背、去溢色、缩放和 alpha 检查。
4. 正式公开范围仅含 512×512 Logo、256×256 Mod 图标、1920×480 README Hero、1280×640 Social Preview 和资产说明；候选图、失败变体、接触表与任务元数据不进入 Git。
5. 最终文件位于 [`docs/assets/brand/`](../../../docs/assets/brand/) 与 [`src/main/resources/assets/textech/textures/promo/`](../../../src/main/resources/assets/textech/textures/promo/)。
