# TeXTech（铽丝科技）品牌视觉设计指南

本文档基于当前代码、手册文案、GUI 主题、材质脚本与 [未来开发愿景](未来开发愿景.md) 提炼，定义 **TeXTech** 的统一品牌身份、世界观、配色与宣传图规格，并附可直接用于 AI 生图的提示词。

## 1. 模组标识

| 字段 | 值 | 说明 |
|------|-----|------|
| **英文品牌名** | **TeXTech** | 代码、GitHub、CurseForge 等对外英文名；`Te` + `XTech`，呼应「铽（Terbium）」与「科技」 |
| **中文显示名** | **铽丝科技** | 游戏内按键分类、玩家向称呼（`key.categories.textech`） |
| **Mod ID** | `textech` | 资源路径 `assets/textech/` |
| **旧 Mod ID** | `advancedatamonitor` | 已迁移，勿在新物料中使用 |
| **一句话 Slogan** | *从数据洪流中编织现实，用二进制之线缝合物与质。* | 愿景文档与品牌核心 |
| **英文 Slogan** | *Weaving reality from the torrent of data, stitching matter with threads of binary.* | 国际宣传 |
| **定位** | GTNH 社区工具模组 | AE2 数据可视化 + 逆向编织 + AI 助手 + 基地体验增强 |
| **目标平台** | Minecraft 1.7.10 / Forge / GTNH 生态 | 视觉需兼容像素风与 GregTech 工业美学 |

### 1.1 命名语义

- **铽（Terbium, Tb）**：稀土元素，象征「在 GTNH 终局稀有物质中提炼出的高阶技术」；与模组中 **数据编织**、**监视器** 的精密感呼应。
- **丝**：数据如丝线的隐喻——AE2 网络中的物品类型、NBT 字段、流体与源质，皆可被「织入」或「织出」。
- **TeXTech**：开发侧简洁标识；`X` 可解读为「交叉（AE2 × GT × 可视化）」或「未知技术变量」。

### 1.2 品牌语气

| 维度 | 倾向 | 避免 |
|------|------|------|
| 叙事 | 冷静、工程化、带一丝宇宙尺度 | 低幼、纯魔幻、与 GT 硬核脱节 |
| 文案 | 短句 + 技术名词（编织、映录、链接、频道） | 过度网梗、破坏沉浸 |
| 视觉 | 深空工业 + AE2 青辉 + GT 金属 | 高饱和卡通、与 AE2/GT 风格冲突的塑料感 |

## 2. 世界观与设定

### 2.1 宇宙坐标

TeXTech 的故事发生 **GregTech: New Horizons 的同一宇宙**中，时间线位于玩家已大规模部署 AE2 网络、数字矿机与自动化产线之后。当存储字节与物品种类趋近天文数字，一个问题浮现：

> **我们还能用这些数据做什么？**

Applied Energistics 将物质 **数字化** 为网络中的类型与数量；TeXTech 的研究者走相反方向——将 **数字化记录逆向编织为真实物质**。

### 2.2 核心设定：数据编织（Data Weaving）

| 概念 | 设定 |
|------|------|
| **正向路径** | AE2：物质 → 扫描 → 存储为数据 |
| **逆向路径** | 数据编织元件：网络中的类型记录 → 缓慢「织出」粉尘、物品、流体、源质 |
| **监视器** | 高级数据监视器：把 TileEntity / AE2 的 NBT 与统计 **映录** 到世界中的图表与文字 |
| **映录** | 数据映录器：捕获链接器 NBT，成为监视器的「数据源指纹」 |
| **次元口袋** | 绑定玩家 UUID 的 **私人数据褶皱**——存储不随物品堆叠，而持久化于世界存档 |
| **挂索** | 在宏大基地中，移动本身应是 **旅程** 而非传送的一帧跳过 |

### 2.3 四大系统（玩家可感知叙事柱）

1. **看见数据** — 高级数据监视器、三类 AE2 链接器、物质球解压器  
2. **编织物质** — 织尘 / 织形 / 涌流 / 织潮 / 织源元件与编织增幅卡  
3. **对话自动化** — AI 助手、语音助手、高级计划器  
4. **传奇与体验** — 超能砂糖桔、至高天圣裁、挂索、次元口袋  

### 2.4 故事线（当前实现 + 愿景伏笔）

#### 已落地叙事

- **数据织尘元件**：技术未成熟，只能编织最简单形态（GT 粉尘前缀）。  
- **数据织形元件**：完全掌握后，可重构任意复杂物品。  
- **涌流 / 织潮 / 织源**：流体与 Thaumcraft 源质的编织通道。  
- **超能砂糖桔**：地牢与击杀极低概率掉落的 **传奇实用** 造物；伴随无人机，可瞬间挖掘、物质球转换。  
- **至高天圣裁**：终局 **毁灭性** 圣剑，宇宙着色器、即死、剑雨与范围审判。  
- **挂索**：工程师为「欣赏自己建造的产线」而设计的基地交通美学。

#### 愿景伏笔（见未来开发愿景，非当前玩法）

- 第一批超能砂糖桔并非在合成台诞生，而在 **失落的数据神殿** 中被编织出来。  
- 物质重构祭坛、维度数据编织器等，将揭示「**空间本身也是可下载的数据**」。  
- 超能砂糖桔与至高天圣裁背后，隐藏 **数据编织起源** 的更大故事线。

### 2.5 关键角色视角（无 NPC，以「研究者手记」口吻）

> *「AE 教会我们：一切皆可编码。我们在监视器的折线图中看见了网络的呼吸——字节涨落、类型繁衍、CPU 的脉搏。然后有人问：若存储的是铁，能否用 **类型本身** 织出铁？织尘元件是第一个答案，粗糙、缓慢、只懂粉尘。织形元件是第二个答案。而口袋……那是把存储空间缝进灵魂褶皱里的尝试。」*  
> —— 《铽丝科技手册》虚构卷首语风格

## 3. 视觉风格总纲

### 3.1 美术流派

**GTNH 工业科幻 × AE2 存储美学 × 深空数据可视化**

- **物品**：16×16 像素为主；编织元件采用 AE2 存储元件外壳 + 中心动态符号（环、立方、液面、漩涡）。  
- **方块**：监视器为 **3D TESR 模型**（`AdvanceDataMonitor.obj`）；链接器为带屏幕/端口的金属块面。  
- **GUI**：深蓝底 + 青色描边 + 9-slice 科幻面板（`adm_ui_atlas.png`）；监视器子 GUI 沿用 `background_ADM_*` 整图拉伸传统。  
- **手册 GUI**：独立配色，偏 **HUD 仪表盘** 风（见 §4.2）。  
- **次元口袋**：裂隙门户、半透明中心、蓝紫网格线（`pocket_portal_panel.png`）。  
- **传奇战斗**：星空剑宇宙 shader、橙金暖色点缀（超能砂糖桔）。

### 3.2 与参考模组的关系

| 参考 | 借鉴 | 差异化 |
|------|------|--------|
| AE2 | 存储元件外形、青色辉光、加速卡轮廓 | 中心图案为「编织环/织网」，非 AE 原版图标 |
| GregTech | 深蓝金属、工业面板、能量接口 | 更多 **数据流/图表** 元素 |
| Applied Energistics 监视 | 链接器「接线」逻辑 | 世界内 **大屏图表** 而非仅终端 UI |

### 3.3 动态材质规范

编织类物品使用 **16×320 竖条、20 帧** 动画（与 AE2 Universe 元件一致），`frametime: 2`，部分带 `interpolate`。

- 织尘：中心粉尘粒子  
- 织形：线框立方旋转  
- 涌流：液面涨落  
- 织源：源质漩涡脉冲  
- 编织增幅卡：环状能量追逐 + 拖尾

### 4.4 编织辉光梯度（代码常量）

自 `tools/generate_loom_textures.py`：

```
ambient  → (0, 95, 120)
base     → (0, 155, 190)
bright   → (40, 215, 245)
hot core → (150, 255, 255)
```

### 4.5 配色使用原则

1. **7:2:1**：70% 深空蓝黑底、20% 青系辉光、10% 功能/传奇点缀（橙、紫、金）。  
2. **GUI 内**：容器框架用 ADM atlas；手册/AI 可用更亮青字。  
3. **宣传图**：允许比游戏内更高的对比与体积光，但 **色相不得偏离** 上述主色板。  
4. **避免**：纯绿作为主色（易与 GT 电路混淆）、高饱和粉、扁平 Material Design 圆角。

## 5. 字体与排版

| 场景 | 规范 |
|------|------|
| 游戏内 | Minecraft 默认位图字体；中文依赖整合包字体包 |
| 宣传 / 手册封面 | 无衬线几何体（如 Eurostile、Orbitron、思源黑体 Heavy）；英文 TeXTech 可全大写或 `TeX` 小写 x 强调 |
| 标题层级 | H1 品牌名 + 青色下划线；H2 章节青 `#20B8E0`；正文 `#C8E0FF` 于深底 |
| 数据/代码感 | 等宽字体展示 NBT、Mod ID、配置键 |

**Logo 字标建议**：`TeX` 用核心青 `#00FFFF`，`Tech` 用侧栏字 `#C8E0FF`，底纹为 faint 六边形网格或二进制 0101 纹理（透明度 5–8%）。
