# TeXTech 卡牌对战 UI 设计

精品化前端（`cardbattle-frontend/`）的视觉与交互约定。规则逻辑见 [rules.md](./rules.md)。

## 视觉方向

- **UI 壳**：电影化 GTNH 工业风（深色金属、主题辉光、圆角战场、分层玻璃面板），卡牌主题仍保留玩家自有美术方向
- **战斗工作区**：宽屏使用左侧决策/法术栈、中间战场/手牌、右侧卡牌档案三栏；窄屏降级为单列并保持棋盘横向可读
- **棋盘皮肤**：可解锁战场背景（`src/lib/skins.ts`）
  - `gt_factory` 格雷工厂（默认）
  - `thaum_workshop` 神秘工坊（累计胜 2）
  - `astral_observatory` 星辉观象台（累计胜 5）
  - `overclocked_nexus` 超频主机（击败一轮 PvE 终局首领）
- **卡面**：按 10 主题各自风格；费用/攻血/关键词与「慢速 / 快速 / 爆发」角标由 UI 叠加，不烘焙进图

## 技术栈

| 库 | 用途 |
|----|------|
| Framer Motion | 组件挂载、手牌扇形、选中抬起、布局过渡 |
| `@use-gesture/react` | 指针拖拽出牌 |
| GSAP | 战斗结算时序（逐卡冲锋、斩击闪光、伤害数字、回弹、冲击环） |

## 交互

1. **开局调度**：四张起手牌逐张切换「保留 / 将替换」，确认按钮显示替换数量；提交 `confirm_mulligan` 后锁定选择并等待对手，双方完成才展示主棋盘
2. **拖拽出牌**（持有行动权时）：手牌按下 → 拖到己方**备战区**（单位/结构自动落空位）或法术要求的对应目标 → 合法金绿高亮 / 非法红边 → 松手用 `elementFromPoint` 解析 `[data-drop]` 后发 `play_card`；定向法术按卡表 `effect.target` 检查单位、机器、隐秘、不可选中和冷却目标约束，响应窗口还会拒绝单位、结构与慢速法术，服务端再执行同一套权威校验
3. **点击 fallback**：先点手牌再点槽位或「出到备战区」按钮
4. **完整预览**：卡牌悬停、键盘聚焦或点选会更新右侧档案；档案显示 `rulesZh` 精确效果、速度说明、目标约束、关键词释义、源质与场上实时攻/血/甲/冷却。锁定按钮可防止后续悬停覆盖
5. **情境操作**：操作栏只显示当前阶段有效动作；`发起攻击` 只在拥有攻击标记且场上存在可攻击单位时显示，`放弃行动权` 连续两次结束轮次；顶部 **Battle Coach** 单行提示当前可做的事（设置里可关，`localStorage.textech_cb_coach`）
6. **攻击声明（LoR 双排）**：备战区单位拖入战场行加入攻击队列，战场内左右拖调整顺序，拖回备战区取消该单位进攻；确认发送 `declare_attacks` 的 `instanceIds`；空选=取消并保留攻击标记
7. **格挡编排**：将己方备战区单位拖到敌方战场攻击位前方；已占用的防守单位不能再次选择；保留下拉 fallback；响应期格挡者离场后仍保留幽灵格挡
8. **法术响应**：`spell_response` / `combat_response` 显示独立法术栈面板；栈顶必须排在第一项，每层显示施法者与速度，空栈也要显示战斗尚待双方确认；按钮文案区分「放弃响应」「结算法术栈」「结算战斗」
9. **攻击响应**：格挡与神秘换位完成后先显示战斗响应；手牌只允许快速/爆发法术，另提供「跳过神秘换位」以避免防守方被锁死；神秘换位改为点选备战区两个槽
10. **冒险地图**：按列展示普通、精英与首领节点；可达、完成和未接通状态必须可辨识

## 动画清单

| 事件 | 表现 |
|------|------|
| 阶段切换 | 顶部 `PhaseBanner` 滑入 |
| Nexus 掉血 | 浮动伤害数字 + 震屏 + 红色 vignette |
| Nexus 回血 | 绿色浮动数字 |
| 攻击结算 | 按攻击队列逐张复制卡牌幽灵，从攻击槽冲向格挡槽或 Nexus；命中时显示斩击闪光与攻击值，再回弹淡出 |
| 场面变化 | GSAP 冲击环 + 像素尘 |
| 单位离场 | 槽位亮度闪白 |
| 胜负 | 全屏遮罩 + 奖励选择 |

## 卡面资产

- 运行时：独立生产后端使用 `cardbattle-server/public/card-art/<id>.png`；可选模组内嵌版使用 jar `assets/textech/cardbattle/card-art/`
- **风格合同**：HD 1:1「体素感游戏内截图」（立方体体块、硬边材质、居中主体、暗角），不是低像素精灵；费用/攻血/关键词由 UI 叠加
- **生成**：`.cursor/skills/textech-card-art/`；默认探路后端为自有 GPT Image 2（`TEXTECH_IMAGE_*`），质量兜底为 Meowa `image-2-run`（`MEOWART_API_KEY`）
- **参考**：每主题 style 金样 + 可选模组贴图索引（`npm run art:index-refs` → `art:requirements` 写入 `styleRefs`/`subjectRefs`）
- **A/B**：`npm run art:ab` 对比 diy/meowa，再决定量产默认后端
- 缺少 PNG 时前端必须显示主题占位底图，不能渲染空白卡面
- 生图凭据只能通过本机环境变量提供，禁止写入仓库、命令参数或日志
