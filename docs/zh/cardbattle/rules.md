# 卡牌规则 V1

## 回合（LoR 味）

1. **主阶段**：出牌（单位/结构占 6 格之一；法术结算）
2. **攻击声明**：主动方选择攻击单位顺序
3. **格挡声明**：防守方为每次攻击指定格挡者或空放过
4. **额外移动（神秘）**：若己方单位同时拥有 `ordo`+`aer`，可交换两个己方槽位一次
5. **结算**：单位互砍或打 Nexus；AOE 溅射左右；隐秘仅能被隐秘格挡
6. **回合结束**：结构产费 / 蜂箱计时 / 电容入库；攻防交换

## 电压

- 己方每高一档电压：受到的 Nexus 伤害 ×(1 − 5%×档数)，下限 25%
- 进攻方电压低于防守方：每差一档输出 ×(1 − 35%)，下限 15%
- 卡组可带主题数：`THEME_SLOTS_BY_VOLTAGE`（ULV/LV=1 … UHV=5）

## 主题钩子

| 主题 | 机制 |
|------|------|
| 原版 | 高数值白板 |
| GT | 机器产费；电容囤费；超额爆炸自伤并拆机器 |
| 神秘 | 源质；秩序+风换位 |
| 林业 | 蜂箱占格不可被攻；产蜂/合并；插件与杂交关键词 |
| 星辉 | 玩家减伤%；反弹；廉价实用 |
| 无尽 | 奇点进度 → 永恒奇点斩杀格挡 |
| 等价交换 | 加速蜂箱/结构冷却 |
| 基因突变 | 低费铺场、克隆/虫群 |
| AE | 从「不在卡组」池生成外卡 |
| DLB | 周期性强制保留进攻权 / 法术强制换边 |
