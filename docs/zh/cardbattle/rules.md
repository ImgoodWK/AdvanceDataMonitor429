# 卡牌规则 V2

## 开局调度

1. 双方各抽 4 张起手牌并进入 `mulligan` 阶段；每名玩家只能确认一次，可选择替换任意张，也可全部保留。
2. 系统先按所选索引从当前牌库补入新牌，再把换下的牌洗回牌库，因此本次调度不会立即抽回刚换下的那一张。
3. 重复、越界或无法补足的替换索引会整体拒绝，不改变手牌、牌库或确认状态。AI 默认替换所有 5 费及以上的起手牌；双方确认后各执行一次正常轮次抽牌，再以 5 张手牌进入首轮主阶段。

## 手牌与牌库

- 手牌上限为 10 张。从牌库抽取或由 AE 效果生成的第 11 张及后续卡牌会公开记录为爆牌并进入弃牌堆。
- 玩家在牌库为空时再次尝试抽牌会立即落败；普通抽牌、法术抽牌和轮次开始抽牌使用同一判定。

## 轮次与行动权

1. 轮次开始时双方补满普通法力、所有存活单位恢复至最大生命、各抽 1 张；攻击标记持有者先获得行动权。
2. 打出单位、结构、慢速法术或快速法术会消耗一次行动并把行动权交给对手；爆发法术立即结算且保留行动权。任意非放弃行动会清空连续放弃计数。
3. 主行动中一方放弃后，对手仍可行动；双方连续放弃才结束轮次。响应窗口使用独立的 `responsePasses`，不会累计或触发主行动的轮次结束。
4. 轮次结束时攻击标记默认换边，双方未用普通法力先补入最多 3 点法术法力，再处理 GT 电容库存。
5. 所有卡牌先消耗普通法力；法术不足时再消耗法术法力，最后使用 GT 电容库存。单位和结构不能使用法术法力。
6. 出牌会先完整校验费用、备战区空位与法术目标，再提交法力、手牌和场面变更；非法请求不会消耗资源或交出行动权。单位与结构进入场面后不会提前进入弃牌堆，只有离场时才进入。定向法术必须选中效果要求的合法单位、机器结构、隐秘单位或带冷却结构。备战区在单位离场后自动向左挤紧。

## 法术速度、法术栈与响应

| 速度 | 可打出时机 | 入栈 | 行动权 |
|------|------------|------|--------|
| 慢速 `slow` | 仅空栈的 `main` | 是 | 交给对手 |
| 快速 `fast` | 空栈 `main`、`spell_response`、`combat_response` | 是 | 交给对手 |
| 爆发 `burst` | `main` 或任一响应窗口 | 否，立即结算 | 施法者保留 |

1. 每张法术在卡表的 `spellSpeed` 字段中声明速度；前端卡面用「慢速 / 快速 / 爆发」角标显示。
2. 慢速或快速法术完成费用与目标校验后，从手牌移入公开 `spellStack`，其中保存 `stackId`、`caster`、`cardId`、速度和目标。法术结算或失效后才进入施法者弃牌堆。
3. 法术入栈会进入 `spell_response`，并把响应行动权交给对手。响应方可追加快速法术、立即打出爆发法术或使用 `pass_priority` 放弃响应；单位、结构和慢速法术会被整体拒绝。
4. 双方连续放弃响应后，整条法术栈按后进先出（栈顶到栈底）结算。上层效果使目标消失或变得不合法时，下层定向法术失效，但仍进入弃牌堆。
5. 主行动法术栈结算后，行动权回到最初施法者的对手。响应放弃不会增加 `consecutivePasses`，所以法术结算不会意外结束轮次。
6. 协议继续复用 `play_card` 与 `pass_priority`；公开状态新增 `spell_response` / `combat_response`、`spellStack`、`responsePasses` 和 `responseOriginPlayer`。

## 攻击与格挡

1. 只有当前持有且尚未消耗攻击标记的玩家可以发起攻击。
2. 场面采用 LoR 式双排：**备战区（Bench）** 最多 6 个单位/结构并自动向左挤紧；**战场行（Battlefield）** 仅在战斗编排时使用，左→右为攻击顺序（公开字段 `attackOrderIds`）。
3. 单位与结构打出到备战区，不必指定死槽；服务端使用第一个空位（可选 `preferSlot`/`targetSlot`）。结构不能进入战场行。
4. 进攻方将备战区单位拖入战场行并确认；提交空列表会取消攻击声明并保留攻击标记；非空攻击在本轮战斗结算后消耗标记。
5. 防守方将备战区单位拖到对应攻击位格挡或放行；同一单位不能重复格挡，结构不能格挡，隐秘只能由隐秘格挡。
6. 若防守方单位同时拥有 `ordo` + `aer`，格挡确认后可交换己方备战区两个槽位，也可用 `pass_swap` 主动跳过。
7. 格挡与可选换位完成后进入 `combat_response`；进攻方先获得响应行动权，双方可打出快速/爆发法术。双方连续放弃响应后先按 LIFO 结算法术栈，再结算战斗伤害。
8. 单位互相造成伤害；未被格挡者攻击 Nexus；已声明的格挡者在响应期离场时仍留下幽灵格挡，该攻击不会改为直击 Nexus。AOE 溅射相邻槽位，吸血治疗进攻方 Nexus。
9. `combatAttacker` 在响应期间保持冻结，攻击标记仍可用；只有战斗实际结算后才消耗标记并清空攻击/格挡数据。战斗后回到交替行动窗口。

## 电压

- 己方每高一档电压：受到的 Nexus 伤害 ×(1 − 5%×档数)，下限 25%
- 进攻方电压低于防守方：每差一档输出 ×(1 − 35%)，下限 15%
- 卡组可带主题数：`THEME_SLOTS_BY_VOLTAGE`（ULV/LV=1 … UHV=5）

## 主题钩子

| 主题 | 机制 | 节奏 |
|------|------|------|
| 原版 | 高数值白板 | 快攻 |
| GT | 机器产费；电容囤费；超额爆炸自伤并拆机器 | 中速 |
| 神秘 | 源质；秩序+风换位 | 中速 |
| 林业 | 蜂箱占格不可被攻；产蜂/合并；插件与杂交关键词 | 快攻 |
| 星辉 | 玩家减伤%；反弹；廉价实用 | 中速 |
| 无尽 | 奇点进度 → 永恒奇点斩杀格挡 | 后期 |
| 等价交换 | 加速蜂箱/结构冷却 | 后期 |
| 基因突变 | 低费铺场、克隆/虫群 | 快攻 |
| AE | 从「不在卡组」池生成外卡 | 中速 |
| DLB | 周期性强制保留进攻权 / 法术强制换边 | 快攻 |

每主题卡表 **40** 张；组牌时按所选主题取牌并垫至至少 **40** 张。法术效果优先走卡表 `effect` 字段（伤害/治疗/抽牌/召唤等通用结算），主题钩子保留特判。快攻主题偏重低费单位与快速/爆发法术；后期主题偏重低费过渡与高费成型。

## PvE

- 路线图共 4 层：两个起始普通节点、第二次分支、精英节点与共享终局首领；只能进入 `availableStageIds` 中的节点。
- 普通、精英、首领有递增的 Nexus / 初始法力强化；敌方阵营与电压由种子确定。
- 战后从三类奖励中选一项：把地区卡加入本次卡组、获得本次冒险能力，或写入某电压档位的待领取奖励。
- 冒险能力目前包括强化 Nexus、初始法术缓存、第一单位精密工具；开局装备与能力叠加。
- 终局首领的任一战后选择都解锁「超频主机」棋盘皮肤。
- 真实 GTNH 物品仍由未来模组桥接发放；当前只写版本化 pending 队列。

## 独立持久化

- `RunState` 与权威 `BattleState` 以版本化 JSON 写入 `CARDBATTLE_DATA_DIR/sessions/`，采用临时文件 + 原子替换，服务重启后可按 ID 恢复。
- 浏览器把活动 `runId` / `matchId` 保存在本地，仅作为恢复索引；所有战斗状态仍以后端文件为权威。
- 待桥接物品奖励始终写入独立奖励账本。没有 MC 服务端或单人存档桥接时只累计，不会自动标记领取。
