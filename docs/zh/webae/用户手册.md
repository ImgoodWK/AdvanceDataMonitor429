## 1. 概述

WebAE 控制台（Web 控制台）是 TeXTech 提供的 **浏览器可访问** HTTP 管理面板。通过任意现代浏览器即可实时查看 AE2 存储、电力、GT 机器状态，搜索配方，编辑样板，提交合成订单，并与游戏内聊天互通。

| 功能 | 说明 |
|------|------|
| 仪表盘 | 128 套配色 × 30 种布局 × 126 种页面样式（含大胆/batch2/batch3/Printstream 印花集 batch4 / Auraeco batch5 构图与 22 种结构大改布局），设置页缩略预览块选配色/布局/样式/预设；可拖拽自定义 widget 网格 |
| 存储 / 流体 / 源质 | 独立侧栏页；存储页亦含物品/流体/源质子表与总览 |
| 合成处理器 | 独立菜单查看 AE2 合成处理器状态与详情 |
| 电力监控 | 可配置布局：EU/蒸汽仪表、入出速率、双序列趋势图 |
| GT 机器 | 查看在线 GT 机器的运行状态、进度、当前配方 |
| 配方搜索 | 服务端上传后，在网页点「获取配方」同步到浏览器 IndexedDB，本地模糊搜索；支持合并/缩略/详细布局 |
| 样板管理 | 查看、新建、编辑、注入 AE2 样板到 ME 接口 |
| AE 下单 | 按样板/物品/材料树提交单笔合成订单，可选 CPU，真实 AE2 进度追踪 |
| 网络拓扑 | 逻辑/空间/P2P/**世界地图** 四视图；频道预算车道（致密 32→4×智能 8）与角色舱；CSV 导出 |
| 任务书 | BetterQuesting 任务线/路线图/提交协助（需安装 BQ） |
| 链接扫描器 | 浏览游戏内扫描结果、别名与传送 |
| 监视器绑定 | 只读查看图表槽位；单槽折线预览 Drawer |
| 计划器 | 同步查看/管理高级计划器条目 |
| AI 助手 | 网页端对话入口（复用游戏内助手能力） |
| 告警历史 | 查看自动化告警记录；规则见设置/告警编辑 |
| Spark 性能分析 | 需安装 Spark 模组；OP 可发起/停止 profiler，所有登录用户可查看历史、打开 Viewer 并对比运行元数据 |
| 聊天 | 网页端与游戏内聊天互通，查看在线玩家列表 |
| 命令上传 | OP 用 `/textech web recipes upload`、`/textech web icons upload` 触发配方/图标上传（无游戏内快捷键） |

默认访问地址：`http://127.0.0.1:8090`（端口可在配置中修改）。

## 2. 启用与配置

Web 控制台默认 **关闭**。在 `config/textech/textech.cfg` 中修改 `[webConsole]` 节：

```ini
[webConsole]
enabled=true
port=8090
bindAddress=127.0.0.1
refreshIntervalMs=1000
gtRefreshIntervalMs=10000
maxNetworksDisplayed=5
tokenLifetimeHours=0
maxRecipeCacheMB=256
recipeCacheMode=full
recipeUploadBatchesPerTick=3
recipeSearchMinIntervalMs=1000
recipeKeepMemoryAfterUpload=false
recipeSyncChunkSize=400
nesqlRepositoryPath=
neiDeepScanItemsPerTick=0
iconMissingDispatchPerTick=8
iconDirectRenderEnabled=false
iconDirectRenderTimeoutMs=3000
iconDirectRenderPerTick=4
powerSampleWindowSeconds=60
gtDefaultScanRadius=16
recipeUploadEnabled=true
iconCacheEnabled=true
iconUploadEnabled=true
iconPackEnabled=true
sparkEnabled=true
sparkMaxHistory=50
sparkDefaultDurationSeconds=30
sparkMaxDurationSeconds=300
```

修改后 **重启服务端** 即可生效。常用项：

- `refreshIntervalMs`：服务端采集与前端轮询的统一刷新间隔（毫秒），默认 1000，最低 1000。
- `gtRefreshIntervalMs`：GT 机器采集间隔（毫秒），默认 10000。
- `maxNetworksDisplayed`：网页同时显示的网络数上限（1–20，默认 5）。
- `tokenLifetimeHours`：Token 有效期（小时），0 = 永不过期。
- `recipeCacheMode`：`full`（GTNH 默认，不 LRU 淘汰）或 `lru`（超过 `maxRecipeCacheMB` 时淘汰；仅服务端内存已加载时生效）。
- `recipeKeepMemoryAfterUpload`：上传写盘后是否保留服务端内存全量配方；默认 `false`（清堆，由浏览器「获取配方」分块同步）。
- `recipeSyncChunkSize`：浏览器同步每块配方条数（默认 400）。
- `nesqlRepositoryPath`：NESQL 仓库根路径，供 `/textech web icons import-nesql` 使用。**留空时默认** `<实例根>/TeXTech/WebAE/`（客户端为 `.minecraft/TeXTech/WebAE/`，专用服为服务端根目录下同名文件夹；与配方本地导出目录相同）。
- `bindAddress=127.0.0.1` 仅本机访问；改 `0.0.0.0` 开放局域网（请配合防火墙）。
- `sparkEnabled` 默认开启，但仅在安装 Spark（Forge 1.7.10）时生效；没有 Spark 时 Spark 页面、接口会自动隐藏/返回不可用。
- `sparkMaxHistory` 控制服务端保留的运行记录数量；记录写入 `TeXTech/WebAE/spark-history.json`，包含状态、发起者、输出摘要和 Spark Viewer URL。
- `sparkDefaultDurationSeconds` 与 `sparkMaxDurationSeconds` 控制网页采样时长。启动/停止/删除历史需要 WebAE 管理员权限，避免普通网页访问者意外增加服务器开销。
- Spark 页面可查看单次输出并打开官方 Viewer；勾选两条记录可比较状态、时长、输出行数和 Viewer 链接。调用树仍由 Spark Viewer 展示。

完整配置项说明见 [开发者手册 §4](开发者手册.md#4-配置)。

## 3. 获取访问令牌

**命令索引**：游戏内执行 `/textech help`（别名 `/adm`、`/txt`）可查看全部域入口（`ai` / `assistant` / `web`）。Web 域主推 `/textech web …`；旧根命令 `/admweb`（及 `/adm-web`、`/webconsole`）仍可用。

Web 控制台需要 Token 认证。在游戏中（或服务端控制台）使用命令：

| 命令 | 说明 |
|------|------|
| `/textech web issue` | 生成**主人** Token（须至少拥有 1 块高级数据监视器；完整值仅显示一次） |
| `/textech web login` | 生成 **6 位浏览器登录码**（5 分钟有效、单次使用；无需 OP 签发 Token） |
| `/textech web guest <玩家名>` | 监视器主人向**在线**访客私发**访客** Token（访问同一套 AE 网络；聊天显示访客名） |
| `/textech web copy` | 将当前活跃 Token 复制到剪贴板 |
| `/textech web list` | 列出 Token 类型、owner、actor（仅 OP） |
| `/textech web revoke [访客名]` | 撤销自己的主人 Token；主人可撤销指定访客 Token；OP 可撤销他人 |
| `/textech web reload` | 重载 TeXTech 配置；`enabled`/`port`/`bindAddress` 等仍需重启服务端（仅 OP） |
| `/textech web refresh [网络]` | 管理员强制重采集快照（仅 OP） |
| `/textech web server status` | 查看 WebAE HTTP 服务运行状态 |
| `/textech web server restart` | 重启 HTTP 服务（仅 OP） |
| `/textech web recipes upload [snapshot\|deep]` / `export` | **OP** 触发自己客户端采集上传 NEI 配方到服务端磁盘；同时写入客户端 `<实例根>/TeXTech/WebAE/web-recipes.json`；网页还需点「获取配方」；`snapshot` 仅采集存储相关物品配方（日常推荐）；`deep` 全量 NEI 物品扫描（耗时） |
| `/textech web recipes status` | 查看配方缓存状态（含磁盘缓存大小） |
| `/textech web recipes clear` | 清空配方内存+磁盘缓存（仅 OP） |
| `/textech web icons upload [pack]` / `upload snapshot [pack]` | **OP** 触发客户端渲染并上传到服务端 |
| `/textech web icons local [pack]` / `local snapshot [pack]` | 任意在线玩家：渲到本机 `TeXTech/WebAE/icons-local/`（不上传） |
| `/textech web icons pull [pack]` | 任意在线玩家：把服务端已有 PNG 拉到本机 `icons-local/` |
| `/textech web icons y` / `n` | 懒加载补渲同意/拒绝（仅当 `iconLazyCaptureEnabled=true`） |
| `/textech web icons render <itemId> [pack]` | **OP** 渲染并上传单个物品图标 |
| `/textech web icons verify <itemId> [pack]` | 打开图标验证 GUI |
| `/textech web icons import <folder> [pack]` | **OP** 从本地文件夹导入 PNG |
| `/textech web icons import-nesql [pack] [subpath]` | **OP** 从 `nesqlRepositoryPath`（默认 `TeXTech/WebAE/`）导入预渲染 PNG（增量，不覆盖已有） |
| `/textech web icons modes` | 列出当前图标渲染 mode（仅 nei） |
| `/textech web icons status` | 查看已安装图标材质包与配置状态 |
| `/textech web icons clear` | 清空全部图标材质包（仅 OP；异步，不阻塞游戏，完成后聊天提示） |
| `/textech web worldmap upload [networkId]` | 上传世界地图快照（须在 AE 网络附近；客户端采集） |
| `/textech web worldmap accept <requestId>` | 同意访客/网页发起的地图上传请求（兼容旧用法） |
| `/textech web wm y [id]` | **推荐** 同意地图上传；可省略 id；聊天中点击「接受」等效 |
| `/textech web wm n [id]` | 拒绝地图上传请求 |
| `/textech web wm up [networkId]` | 等同 `worldmap upload` |
| `/textech web wm st [networkId]` | 等同 `worldmap status` |
| `/textech web worldmap status [networkId]` | 查看地图快照采集状态 |
| `/textech web help` | 显示用法（含 recipes/icons/worldmap/server 分组 help） |

**Token 类型**

- **主人 Token**：绑定监视器主人 UUID，可读写其名下全部监视器所连 AE 网络；**不要求主人在线**。
- **访客 Token**：由主人 `/textech web guest`（别名 `/admweb guest`）签发，读写权限与主人 Token 接近（AE 操作仍按主人身份），网页/游戏内聊天显示访客名。
- Token 数据写入 `TeXTech/WebAE/web-tokens.json`；旧格式条目首次加载时自动迁移为 `type: owner`。

**离线访问与区块**

- 仅**已加载区块**内的高级数据监视器会被发现；跨维度监视器的 `monitorDim` 已按监视器所在维度采集。
- 基地需常加载或使用区块加载器，否则网页网络列表可能为空。

## 4. 浏览器访问

1. 确认服务端已启动且 `enabled=true`
2. 打开浏览器，访问 `http://127.0.0.1:8090`（或服管配置的地址与端口）
3. 在登录页输入 `/textech web issue` 获取的 Token
4. Token 存储在浏览器 `localStorage` 中；**自动登录**（默认开启）会在下次访问时自动重连
5. 若 Token 过期或被撤销，登录页会提示并清除本地 Token，请重新签发
6. 需要更换 Token 时，在设置页输入新 Token 即可立即重连
7. 可在设置页关闭「自动登录」

## 5. 功能页面

### 存储监控

顶部为可配置总览 widget 行（GridStack 编辑模式；默认物品种类/流体种类/字节占用率等）。下方子表含物品/流体/源质。支持列头排序、搜索过滤；顶栏多网络「分开」/「合并」聚合。

### 合成处理器

独立侧边栏菜单。可配置总览 + CPU 列表表格。点击行打开详情 Drawer（坐标、网络、存储、当前任务、预计剩余）。多网络 split 模式用 Tabs 切换。

### 电力监控

全页 GridStack 可编辑 widget 网格（默认 EU 仪表、入/出速率、蒸汽进度条、EU+蒸汽双序列趋势图等）。点「编辑布局」可拖拽、添加/删除组件。多网络「分开」模式下用 Tabs 切换；自动刷新时趋势图不闪烁。

### GT 机器

列表显示在线 GT 机器的名称、工作进度、配方、输入/输出仓物品。支持筛选、文本搜索与排序。

### 配方搜索

配方不常驻服务端内存供浏览器直查。流程：**OP 游戏内上传 → 服务端落盘 → 玩家在配方页点「获取配方」→ 分块写入本浏览器 IndexedDB → 本地浏览/搜索**。

- 进入配方页后点工具栏 **「获取配方」**（有服务端新 revision 时才需要；进度条可取消）。完成后即可模糊搜索、类别多选、完整/合并与缩略/详细布局；数据保存在本浏览器，不会自动重复下载。
- OP 需先执行 `/textech web recipes upload snapshot`（推荐）或 `upload`（全量）；采集同时写入客户端 `.minecraft/TeXTech/WebAE/web-recipes.json`（纯 JSON 备份）。
- 换浏览器/清站点数据后需重新「获取配方」。服务端 `/textech web recipes clear` 只清服务端，不影响已下载的 IndexedDB。

### 物品图标与材质包

物品表与配方输入/输出可显示真实游戏图标，失败时回退为缩写。图标加载采用：**本机目录 → IndexedDB → 服务端磁盘 → 缩写**（懒加载补渲默认关闭）。

- **本机目录**：设置页「选择本机图标目录」指向游戏 `TeXTech/WebAE/icons-local/`（需 Chrome/Edge 且页面为 https 或 localhost；局域网 http://IP 请用 ZIP 导入）。任意玩家可执行 `/textech web icons local` 渲到本机，或 `/textech web icons pull` 从服务端下载。
- **本地优先**：目录/IndexedDB 命中时不打服务端；OP `/textech web icons upload` 或导入写到服务端磁盘后按需请求即可。
- **自动同步（默认关闭）**：设置页「自动同步服务端材质包」开启后，登录时若版本变化会整包下载到 IndexedDB。
- **手动获取**：设置页「同步整包」；「补当前可见缺失」仅请求已有 PNG（不会默认触发游戏内渲染）。
- **服务端缓存**：OP `/textech web icons upload` / `import-nesql`；渲染固定 **`nei`**（NESQL 同款 64×64 FBO）。若磁盘 PNG 出现方形/异形缺块，用新版本模组重跑 upload 覆盖；网页偶发错图时可 **Ctrl+F5** 硬刷新，或清 IndexedDB / 重新选择本机图标目录。
- **GT++（miscutils）缺锭/板/棒图**：旧版全量 upload 会跳过 `getIconIndex==null` 的材质物品（尘有图、锭无图）。磁盘上的 `itemDustMix*` 是「Mix」特殊尘，**不是**锭的错名。请用当前版本重跑 `/textech web icons upload snapshot`（优先）或全量 `upload`；补完后网页 Ctrl+F5。
- **本机目录**：设置页可选 `icons` / `icons-local`；刷新后若浏览器收回权限，点一下页面或「刷新索引」重新授权。
- **同系列 meta 整批变缩写**：前端曾把 `gregtech:gt.metaitem.01:xxxx` 失败误标到裸 `gt.metaitem.01`，导致同物品其它 meta 也不请求。当前版本已改为仅 `:0` 等价标记；硬刷新后应恢复已有 PNG。
- **异步补图（默认关）**：`iconLazyCaptureEnabled` 默认 **false**。开启后缺图才入队，并向候选玩家发聊天同意（说明将使用其材质包外观）。同步直渲仍默认 **false**。
- **多人服建议**：OP 先 `/textech web icons upload snapshot`；玩家用 `icons local` / 选目录 / ZIP。

### 本地数据目录 `TeXTech/WebAE/`

| 路径 | 用途 |
|------|------|
| 客户端 `.minecraft/TeXTech/WebAE/web-recipes.json` | `/textech web recipes upload*` 采集后自动写入的 NEI 配方 JSON |
| 服务端 `TeXTech/WebAE/web-recipes.json` + `.meta.json` + `recipe-chunks/` | 服务端权威缓存；浏览器经「获取配方」分块下载 |
| 服务端 `<实例根>/TeXTech/WebAE/`（或配置的 `nesqlRepositoryPath`） | `/textech web icons import-nesql` 读取 NESQL 预渲染 PNG（常见子目录 `images/`） |

目录在首次使用时自动创建。

### 样板管理

左侧列出网络已有样板，可搜索、多选、批量删除。右侧编辑 9×3 输入网格与输出（含倍率调整）。编码时从 AE 网络扣除空白样板；可注入到 ME 接口。

### 合成下单

顶部可选合成处理器或留空自动分配。「按样板」Tab 分页浏览 Grid + Interface 双源样板，支持虚拟滚动与单笔下单。「按物品」Tab 支持存储搜索与单笔下单。「材料树」Tab 输入 registry 名与数量，递归展开配方链并显示库存缺口（仅查看，不批量下单）。进行中/历史订单每 3 秒刷新；进度来自 AE2 `ICraftingLink` 与 CPU 的合成树步骤计数（与游戏内 CPU GUI 同口径，**不是**最终产物个数）。游戏内取消的任务会进入历史并标注取消。历史订单可点「再次下单」，确认后按原物品与数量重新提交。

### 网络拓扑

侧栏「网络拓扑」提供逻辑分组、空间分区、**P2P 频道** 与 **世界地图** 四种视图。逻辑视图是 **频道预算规划图**（`ae_budget_v2`）：控制器 → 致密干 32 → 四路智能车道（各 8）→ 角色舱（终端/总线/接口等）→ 设备；存储/CPU 等零频道设备挂在控制器环上。这不是真实 AE 布线。也可切换双环摘要。原「线缆模拟」视图已弃用（`topologySimulatedEnabled`，默认关闭）。P2P 视图按 frequency 列出隧道端点；支持 CSV 导出。

#### 世界地图视图

默认采用 **客户端快照**（`worldMapSnapshotMode=client_only`）：地图由在线玩家客户端采集并上传，服务端不渲染。

1. **首次使用**：先采集逻辑拓扑快照，再在网页点击 **「更新地图快照」**，或由网络主人在 AE 网络附近执行 `/textech web wm up`（或 `/textech web worldmap upload`）。
2. **JourneyMap**：整合包已装 JourneyMap 时，优先读取本地最高清 day 瓦片（`worldMapJourneyMapEnabled`，支持 JM 5.x 的 `{x},{z}.png` 命名）；无 JM 时使用低清 GL 快速渲染。**分辨率**：JM 源图约 1 像素/方块（512 px 区域瓦片）；Web 显示清晰度可在控制台选 quality 档位，或在 `textech.cfg` 调整 `webWorldMapDefaultQualityTier` / `webWorldMapMaxQualityTier`（最高 ultra=512 px/chunk）。
3. **访客请求更新**：网页点击「更新地图快照」后，附近玩家会收到带 **接受/拒绝** 可点击文字的聊天提示；也可执行 `/textech web wm y`（可省略 requestId）同意上传。同一请求不会重复刷屏。
4. **设备清单**：地图右上角「设备清单」按钮打开弹窗，不影响地图尺寸。
5. **设备图标与弹窗**：点击单个设备图标或聚类数字，打开**设备缩略列表**（仅含可查看详情的设备类型：接口、驱动器、CPU、总线、箱子、安全终端、等级维持器、控制器、IO 端口、量子桥、能源元件、P2P 等；终端/监视器/发射器/样板供应器不显示）。列表中点击一行打开右侧**详情抽屉**；聚类打开时地图会临时放大 1.5×，关闭弹窗后还原。平移/缩放地图不会自动关闭弹窗；弹窗内滚轮仅滚动列表。**悬停聚类数字**时显示各设备类型图标及数量（xN）。**合成处理器与 ME 控制器**为多方块结构，在聚类计数中各计为 **1 个设备**（详情抽屉仍列出各方块坐标）。
6. **左侧 AE 图例窗**：地图左侧常驻窄色条；鼠标移入展开，可勾选类别可见性、点击色块改色（同时影响 AE 透视层与设备图标描边）；**取消勾选后图例项仍保留**（变暗显示），仅隐藏地图上对应设备图标；锁定后只读（仍可移出收起）；各类别色块上的图标与地图设备图标同源（取该类别首个设备），「其他」仅显示配置色块。原工具栏「AE 着色」按钮已移除。
7. **本地缓存**：浏览器会缓存已下载瓦片（IndexedDB）；换设备登录 MC 后客户端也会同步快照到 `TeXTech/WebAE/map-cache/`。
8. **AE 透视层**：与地形同时采集；**透明度**滑条（拓扑设置）仅影响 AE 设备着色像素（不影响地形）。
9. **滚轮**：在世界地图与树形拓扑视图中滚轮用于缩放，不会滚动整页。
10. **配置**：`worldMapSnapshotMode`、`worldMapJourneyMapEnabled`、`worldMapConsentRadiusChunks`、`worldMapOwnerSkipConsent` 等，详见 [开发者手册 §11.26](开发者手册.md#1126-世界地图视图客户端快照--journeymap)。

### 任务书（BetterQuesting）

需整合包安装 **BetterQuesting**；侧栏「任务书」（`?page=quests`）为 **左侧任务线 | 中间路线图 | 右侧固定详情侧栏** 三栏布局（窄屏 ≤768px 时详情仍用抽屉）；工具栏「任务列表」按钮打开抽屉（含搜索与筛选）。左侧任务线旁显示 **已完成/总数**（如 `12/42`；全部完成时用成功色提示）。

- **图节点**：显示任务物品图标；主线任务（`isMain`）为菱形框，普通为圆角矩形；悬停高亮前后置节点与连线，并弹出任务名称提示（不依赖「显示任务名称」常驻标签开关）；可开关「隐藏已完成」；跨章节前置显示为虚线「外章」幽灵节点。工具栏提供 **放大 / 缩小 / 适应窗口** 与 **设置**（可调节节点间距、节点大小、标签、侧栏与连线等，保存在浏览器 localStorage）；**滚轮**在路线图区域以指针位置缩放（不滚动整页）；拖拽可平移视图。路线图节点名称可单独开关；标签显示去码文本并按首个 `§` 颜色着色。
- **§ 格式码**：任务标题、描述、步骤名等支持 Minecraft `§` 颜色与格式（如 `§a§l`）；详情侧栏与列表完整渲染样式，搜索匹配时会忽略格式码。
- **任务详情**：点击节点在**右侧固定侧栏**展示（无需额外打开抽屉）；区块顺序为关联任务（**前置** / **后续**）、提交条件（来自 BetterQuesting `tasks`）、奖励（来自 `rewards`；`bq_standard:choice` 显示多选一；纯物品奖励可网页领取）。点击前置/后续可跨任务线跳转并居中节点；隐式/隐藏前置显示对应标签。侧栏宽度可在设置中调节（默认 380px）。
- **刷新**：进入页面/切换章节时拉取一次进度与图数据并本地缓存；**无自动轮询**。手动刷新有 **30 秒冷却**；提交/领取相关操作前会强制刷新进度。
- **奖励领取**：当任务为 `UNCLAIMED` 且全部奖励均为可解析的纯物品（`bq_standard:item`）与多选一（`bq_standard:choice`）时，可在详情侧栏先完成选择，再确认「领取至 AE 网络」；物品经 BQ 官方领取后转入当前选中网络。AE 空间不足时拒绝领取并保持未领取。含命令/经验等非物品奖励时仍提示回游戏内领取。访客 Token 不可领取。
- **只读**：访客 Token 可浏览任务线与进度；不可提交、不可领取奖励。
- **Web 可协助**：物品/流体提交、Retrieval/流体持有检测（按 AE 库存完成，**不**把物品/流体装进玩家背包）；合成/击杀/维度类步骤仅展示。**流体单元任务**：DETECT 将游离流体与装满单元（默认 GT/IC2）加总；SUBMIT 优先扣装满单元，不足则用空单元+流体装填（禁止仅有流体）。真流体任务可从单元 drain 所需 mB（余量退回）。提交与「合成后提交」会用 **AE 虚拟 escrow** 锁定物料（合成开始前锁定已有，产物到账后立刻补锁），再提交或完成持有检测，失败/超时退回网络。可点击单个步骤提交；「链式提交」按拓扑顺序处理前置（可配置）。提交面板显示 AE 库存与需求对照；「可合成」仅在已有 AE 样板且材料链可满足时出现。若 `questFluidAllContainersOption=true`，面板可勾选「计入桶/罐等全部流体容器」。
- **离线**：主人不在线时仍可用 Token + FakePlayer 操作（进度写入 **Token 主人** 的 questing UUID）；需服务端运行且对应 AE 网络可解析（Link/区块加载），与其他 WebAE AE 操作前提相同。
- **组队**：Web 提交**不会**同步完成队友进度，只更新 Token owner；BQ 对 FakePlayer 强制单人，本模组未接 PartyManager / SyncPartyQuests。
- **配置**：`textech.cfg` → `[webConsole]` 的 `questEnabled`、`questSubmitEnabled`、`questClaimEnabled`（默认 true）、`questChainSubmitEnabled`（默认 true）、`questSubmitMaxStacks`、`questCraftWaitTimeoutMs`、`questEscrowEnabled`（默认 true）、`questEscrowTimeoutMs`（默认 120000）、`questFluidAllContainersOption`（默认 false）、`questCacheTtlSec`。

### 监视器绑定与预览

侧栏「监视器绑定」只读展示各数据监视器的图表槽位与 GT 绑定坐标。点击槽位「预览」可在 Drawer 中查看与游戏内监视器一致的折线历史（只读，编辑仍在游戏内）。

### 链接扫描器 / 计划器 / AI 助手

- **链接扫描器**：展示游戏内高级链接扫描器的扫描结果，可按所有者/名称过滤并查看坐标（传送仍以游戏内为准）。
- **计划器**：同步高级计划器条目，便于在网页浏览与勾选进度。
- **AI 助手**：网页端对话入口，能力与游戏内助手一致（需已配置 AI；AE 操作仍依赖附近高级网络链接器）。

### 自动化告警与告警历史

`TeXTech/WebAE/web-alerts.json` 驱动库存阈值、CPU 卡住、GT 异常、下单完成与频道超载检测。浏览器除 10 秒轮询外，还通过 SSE（`/api/events/stream`）实时推送新告警；标签页隐藏时暂停连接。侧栏「告警历史」可回看已触发记录。

### 移动端与 PWA

内置 `manifest.webmanifest`，窄屏下自动调整侧栏与表格布局。可将控制台「添加到主屏幕」以便手机查看存储/GT/拓扑（仍建议通过 SSH 隧道访问，勿直接暴露公网）。

### 仪表盘、聊天与设置

- **仪表盘**：GridStack 拖拽布局，**128** 套配色 + **30** 种布局（含底栏导航 / 浮岛侧栏 / 分割壳层，以及 batch3 双轨 / Dock / 影院帷幕 / HUD / 角部枢纽等结构变体）+ **126** 种页面样式（含反应堆 / 蜂窝等克制装饰、不裁切部件内容；另有 batch2 / batch3 / **Printstream 印花集 batch4**（黑白几何、珠光渐变、ASCII 虚线码流等 CS 社区致敬风格）与 **Auraeco batch5**（体素波纹 / 藤蔓孢子 / 穹顶光晕 / 矩阵火花 / 气泡水纹；设置页可搜「Aura / Auraeco」）；设置页以缩略预览块选择配色、布局、样式与 Preset）；折线/柱状/饼图/雷达可在组件编辑里单独选 **图表样式**；其余能力同前。
  - **分组容器（nested grid）**：可添加「分组」组件，把多个子组件收进同一格内整组拖动；编辑模式下点分组标题旁 `+` 向组内添加子组件。
  - **布局/资讯组件**：文本便签、分隔占位、告警摘要、合成队列；编辑模式下可用组件库一键添加，或拖到底部垃圾桶删除。
  - **编辑恢复**：编辑模式下支持撤销/重做（按钮或 Ctrl+Z / Ctrl+Y）；清空全部组件后刷新仍保持空布局；Storage/CPU Overview 组件高度固定为 2 行。
  - **锁定与自适应**：单组件可锁定位置/禁止拖缩、开启「按内容自适应高度」；统计卡/仪表可设告警阈值（超限高亮）。
  - **数据表列与钉选**：编辑数据表组件时，「显示列」会分别控制图标、名称、数量、注册名及各数据源专属字段；「名称」显示物品显示名，「注册名」单独显示物品注册名。允许取消全部列，切换数据源后会采用新数据源的默认列。钉选框聚焦即可从当前库存候选中选择，也可按显示名、注册名或物品 ID 搜索；达到服务端下发的单组件上限时需先移除旧钉选。
- **聊天**：侧栏 💬 进入；网页消息以 `[Web] <玩家名>: 内容` 广播到游戏内。
- **导航栏**：边缘按钮循环展开 → 折叠 → 隐藏三态。
- **顶栏**：连接点旁显示刷新倒计时/状态。
- **备份与恢复**（设置 →「备份与恢复」Tab）：
  - **导出 JSON**：一次性备份主题、各页面布局（主仪表盘 / Storage·CPU·Power 概览 / 拓扑 / 任务书 / 配方 / 聊天等）、刷新与 Debug 偏好；可选包含 Preset 列表与服务端数据（收藏、下单模板；告警规则需 OP）。
  - **导入 JSON**：预览将覆盖的部分，支持合并模式；导入后建议刷新页面使 GridStack 布局完全生效。
  - **恢复整合包默认**：重新应用服务端 `ui-defaults.json`（实例 `TeXTech/WebAE/ui-defaults.json` 优先，否则模组 jar 内置）。
- **整合包作者**：在 WebAE 配好 UI 后导出 JSON，放到实例 `TeXTech/WebAE/ui-defaults.json`，或交给 Agent 写入模组 `assets/textech/webae/ui-defaults.json`；新玩家首次打开（无已有浏览器偏好）会自动应用。OP 亦可用 `/textech web defaults install <路径>` 安装。

## 6. 注意事项

- **默认仅本机访问**：`bindAddress=127.0.0.1` 确保只有本机浏览器能访问
- **局域网访问风险**：改 `0.0.0.0` 后局域网内持有 Token 的设备均可访问，请配合防火墙或 SSH 隧道
- **强制认证**：所有 `/api/` 端点都需要 Token；强制刷新等管理员操作额外要求 OP/admin grant
- **多层权限**：管理员可停用玩家账号（立刻回登录页，提示联系管理员）、停用单个 AE 网（含网主，游戏内 AE 不受影响）、或限制访客只能访问部分网
- **Token 安全**：Token 可查看存储并提交合成，请妥善保管
- **配方需上传并获取**：OP `/textech web recipes upload` 后，各玩家在网页配方页点「获取配方」同步到浏览器 IndexedDB
- **图标上传**：OP 执行 `/textech web icons upload [packName]`；首次加载网页会自动选择服务端记录的最近 pack
- **reload 限制**：`/textech web reload` 不重载 web 服务器监听参数；Token 与运行时数据文件不受影响
