## 1. 概述

WebAE 控制台（Web 控制台）是 TeXTech 提供的 **浏览器可访问** HTTP 管理面板。通过任意现代浏览器即可实时查看 AE2 存储、电力、GT 机器状态，搜索配方，编辑样板，提交合成订单，并与游戏内聊天互通。

| 功能 | 说明 |
|------|------|
| 存储监控 | 实时查看 AE2 网络中物品/流体/源质的类型数、字节使用量 |
| 合成 CPU | 独立菜单查看 AE2 合成 CPU 状态与详情 |
| 电力监控 | 可配置布局：EU/蒸汽仪表、入出速率、双序列趋势图 |
| GT 机器 | 查看在线 GT 机器的运行状态、进度、当前配方 |
| 配方搜索 | 模糊搜索 NEI 配方，支持合并/缩略/详细布局 |
| 样板管理 | 查看、新建、编辑、注入 AE2 样板到 ME 接口 |
| AE 下单 | 按样板/物品/材料树提交合成订单，可选 CPU，混合进度追踪 |
| 网络拓扑 | 逻辑/空间/P2P/**世界地图** 四视图；模拟假线缆与频道；CSV 导出 |
| 监视器绑定 | 只读查看图表槽位；单槽折线预览 Drawer |
| 自动化告警 | 库存/CPU/GT/下单/频道告警；SSE 实时推送 + Toast |
| 聊天 | 网页端与游戏内聊天互通，查看在线玩家列表 |
| 仪表盘 | 24 套配色 × 5 种布局，可拖拽自定义 widget 网格 |
| 命令上传 | OP 用 `/admweb recipes upload`、`/admweb icons upload` 触发配方/图标上传（无游戏内快捷键） |

默认访问地址：`http://127.0.0.1:8090`（端口可在配置中修改）。

## 2. 启用与配置

Web 控制台默认 **关闭**。在 `config/textech/textech.cfg` 中修改 `[webConsole]` 节：

```ini
[webConsole]
enabled=true
port=8090
bindAddress=127.0.0.1
refreshIntervalMs=1000
gtRefreshIntervalMs=10000
maxNetworksDisplayed=5
tokenLifetimeHours=0
maxRecipeCacheMB=256
recipeCacheMode=full
recipeUploadBatchesPerTick=3
recipeSearchMinIntervalMs=300
nesqlRepositoryPath=
neiDeepScanItemsPerTick=0
iconMissingDispatchPerTick=8
powerSampleWindowSeconds=60
gtDefaultScanRadius=16
recipeUploadEnabled=true
iconCacheEnabled=true
iconUploadEnabled=true
iconPackEnabled=true
```

修改后 **重启服务端** 即可生效。常用项：

- `refreshIntervalMs`：服务端采集与前端轮询的统一刷新间隔（毫秒），默认 1000，最低 1000。
- `gtRefreshIntervalMs`：GT 机器采集间隔（毫秒），默认 10000。
- `maxNetworksDisplayed`：网页同时显示的网络数上限（1–20，默认 5）。
- `tokenLifetimeHours`：Token 有效期（小时），0 = 永不过期。
- `recipeCacheMode`：`full`（GTNH 默认，不 LRU 淘汰）或 `lru`（超过 `maxRecipeCacheMB` 时淘汰）。
- `nesqlRepositoryPath`：NESQL 仓库根路径，供 `/admweb icons import-nesql` 使用。**留空时默认** `<实例根>/TeXTech/WebAE/`（客户端为 `.minecraft/TeXTech/WebAE/`，专用服为服务端根目录下同名文件夹；与配方本地导出目录相同）。
- `bindAddress=127.0.0.1` 仅本机访问；改 `0.0.0.0` 开放局域网（请配合防火墙）。

完整配置项说明见 [开发者手册 §4](开发者手册.md#4-配置)。

## 3. 获取访问令牌

**命令索引**：游戏内执行 `/textech help`（别名 `/adm help`、`/txt help`）可查看 TeXTech 全部命令入口；各子命令用 `/xxx help` 查看详细用法（跟随游戏语言显示中/英）。

Web 控制台需要 Token 认证。在游戏中（或服务端控制台）使用命令：

| 命令 | 说明 |
|------|------|
| `/admweb issue` | 生成**主人** Token（须至少拥有 1 块高级数据监视器；完整值仅显示一次） |
| `/admweb login` | 生成 **6 位浏览器登录码**（5 分钟有效、单次使用；无需 OP 签发 Token） |
| `/admweb guest <玩家名>` | 监视器主人向**在线**访客私发**访客** Token（访问同一套 AE 网络；聊天显示访客名） |
| `/admweb copy` | 将当前活跃 Token 复制到剪贴板 |
| `/admweb list` | 列出 Token 类型、owner、actor（仅 OP） |
| `/admweb revoke [访客名]` | 撤销自己的主人 Token；主人可撤销指定访客 Token；OP 可撤销他人 |
| `/admweb reload` | 重载 TeXTech 配置；`enabled`/`port`/`bindAddress` 等仍需重启服务端（仅 OP） |
| `/admweb refresh [网络]` | 管理员强制重采集快照（仅 OP） |
| `/admweb server status` | 查看 WebAE HTTP 服务运行状态 |
| `/admweb server restart` | 重启 HTTP 服务（仅 OP） |
| `/admweb recipes upload [snapshot\|deep]` / `export` | **OP** 触发自己客户端采集上传 NEI 配方；同时写入客户端 `<实例根>/TeXTech/WebAE/web-recipes.json.gz`；`snapshot` 仅采集存储相关物品配方（日常推荐）；`deep` 全量 NEI 物品扫描（耗时） |
| `/admweb recipes status` | 查看配方缓存状态（含磁盘缓存大小） |
| `/admweb recipes clear` | 清空配方内存+磁盘缓存（仅 OP） |
| `/admweb icons upload [pack] [mode\|all\|snapshot]` | **OP** 触发客户端渲染上传物品图标 |
| `/admweb icons render <itemId> [pack] [mode]` | **OP** 渲染并上传单个物品图标 |
| `/admweb icons verify <itemId> [pack]` | 打开图标验证 GUI |
| `/admweb icons import <folder> [pack]` | **OP** 从本地文件夹导入 PNG |
| `/admweb icons import-nesql [pack] [subpath]` | **OP** 从 `nesqlRepositoryPath`（默认 `TeXTech/WebAE/`）导入预渲染 PNG（增量，不覆盖已有） |
| `/admweb icons modes` | 列出全部图标渲染 mode |
| `/admweb icons status` | 查看已安装图标材质包与配置状态 |
| `/admweb icons clear` | 清空全部图标材质包（仅 OP） |
| `/admweb worldmap upload [networkId]` | 上传世界地图快照（须在 AE 网络附近；客户端采集） |
| `/admweb worldmap accept <requestId>` | 同意访客/网页发起的地图上传请求（兼容旧用法） |
| `/admweb wm y [id]` | **推荐** 同意地图上传；可省略 id；聊天中点击「接受」等效 |
| `/admweb wm n [id]` | 拒绝地图上传请求 |
| `/admweb wm up [networkId]` | 等同 `worldmap upload` |
| `/admweb wm st [networkId]` | 等同 `worldmap status` |
| `/admweb worldmap status [networkId]` | 查看地图快照采集状态 |
| `/admweb help` | 显示用法（含 recipes/icons/worldmap/server 分组 help） |

**Token 类型**

- **主人 Token**：绑定监视器主人 UUID，可读写其名下全部监视器所连 AE 网络；**不要求主人在线**。
- **访客 Token**：由主人 `/admweb guest` 签发，读写权限与主人 Token 接近（AE 操作仍按主人身份），网页/游戏内聊天显示访客名。
- Token 数据写入 `TeXTech/WebAE/web-tokens.json`；旧格式条目首次加载时自动迁移为 `type: owner`。

**离线访问与区块**

- 仅**已加载区块**内的高级数据监视器会被发现；跨维度监视器的 `monitorDim` 已按监视器所在维度采集。
- 基地需常加载或使用区块加载器，否则网页网络列表可能为空。

## 4. 浏览器访问

1. 确认服务端已启动且 `enabled=true`
2. 打开浏览器，访问 `http://127.0.0.1:8090`（或服管配置的地址与端口）
3. 在登录页输入 `/admweb issue` 获取的 Token
4. Token 存储在浏览器 `localStorage` 中；**自动登录**（默认开启）会在下次访问时自动重连
5. 若 Token 过期或被撤销，登录页会提示并清除本地 Token，请重新签发
6. 需要更换 Token 时，在设置页输入新 Token 即可立即重连
7. 可在设置页关闭「自动登录」

## 5. 功能页面

### 存储监控

顶部为可配置总览 widget 行（GridStack 编辑模式；默认物品种类/流体种类/字节占用率等）。下方子表含物品/流体/源质。支持列头排序、搜索过滤；顶栏多网络「分开」/「综合」聚合。

### 合成 CPU

独立侧边栏菜单。可配置总览 + CPU 列表表格。点击行打开详情 Drawer（坐标、网络、存储、当前任务、预计剩余）。多网络 split 模式用 Tabs 切换。

### 电力监控

全页 GridStack 可编辑 widget 网格（默认 EU 仪表、入/出速率、蒸汽进度条、EU+蒸汽双序列趋势图等）。点「编辑布局」可拖拽、添加/删除组件。多网络「分开」模式下用 Tabs 切换；自动刷新时趋势图不闪烁。

### GT 机器

列表显示在线 GT 机器的名称、工作进度、配方、输入/输出仓物品。支持筛选、文本搜索与排序。

### 配方搜索

进入页面自动加载配方总览，支持模糊搜索、类别多选、完整/合并显示模式、缩略/详细布局。点击卡片或合并组打开详情弹窗。配方数据需 OP 先执行 `/admweb recipes upload snapshot`（推荐）或 `upload`（全量）上传；采集同时会在客户端写入 `.minecraft/TeXTech/WebAE/web-recipes.json.gz` 供离线备份或外部工具使用。

### 物品图标与材质包

物品表与配方输入/输出可显示真实游戏图标，失败时回退为缩写。OP 执行 `/admweb icons upload [packName]` 或 `/admweb icons import-nesql`（默认从 `TeXTech/WebAE/` 目录导入，可用 `nesqlRepositoryPath` 覆盖）；设置页可切换材质包，管理员可上传 zip。缺失图标经 SSE `icon-ready` 懒加载。

### 本地数据目录 `TeXTech/WebAE/`

| 路径 | 用途 |
|------|------|
| 客户端 `.minecraft/TeXTech/WebAE/web-recipes.json.gz` | `/admweb recipes upload*` 采集后自动写入的 NEI 配方 gzip 缓存 |
| 服务端 `<实例根>/TeXTech/WebAE/`（或配置的 `nesqlRepositoryPath`） | `/admweb icons import-nesql` 读取 NESQL 预渲染 PNG（常见子目录 `images/`） |

目录在首次使用时自动创建。

### 样板管理

左侧列出网络已有样板，可搜索、多选、批量删除。右侧编辑 9×3 输入网格与输出（含倍率调整）。编码时从 AE 网络扣除空白样板；可注入到 ME 接口。

### 合成下单

顶部可选合成 CPU 或留空自动分配。「按样板」Tab 分页浏览 Grid + Interface 双源样板，支持虚拟滚动与批量下单。「按物品」Tab 支持存储搜索与批量下单。「材料树」Tab 输入 registry 名与数量，递归展开配方链并显示库存缺口。活跃/历史订单每 3 秒刷新，进度为 AE2 真实进度 + 时间估算混合方案。

### 网络拓扑

侧栏「网络拓扑」提供逻辑分组、空间分区、**P2P 频道** 与 **世界地图** 四种视图。逻辑/空间为模拟星形假线缆（非真实 AE 布线）；P2P 视图按 frequency 列出隧道端点；支持 CSV 导出。

#### 世界地图视图

默认采用 **客户端快照**（`worldMapSnapshotMode=client_only`）：地图由在线玩家客户端采集并上传，服务端不渲染。

1. **首次使用**：先采集逻辑拓扑快照，再在网页点击 **「更新地图快照」**，或由网络主人在 AE 网络附近执行 `/admweb wm up`（或 `/admweb worldmap upload`）。
2. **JourneyMap**：整合包已装 JourneyMap 时，优先读取本地最高清 day 瓦片（`worldMapJourneyMapEnabled`，支持 JM 5.x 的 `{x},{z}.png` 命名）；无 JM 时使用低清 GL 快速渲染。**分辨率**：JM 源图约 1 像素/方块（512 px 区域瓦片）；Web 显示清晰度可在控制台选 quality 档位，或在 `textech.cfg` 调整 `webWorldMapDefaultQualityTier` / `webWorldMapMaxQualityTier`（最高 ultra=512 px/chunk）。
3. **访客请求更新**：网页点击「更新地图快照」后，附近玩家会收到带 **接受/拒绝** 可点击文字的聊天提示；也可执行 `/admweb wm y`（可省略 requestId）同意上传。同一请求不会重复刷屏。
4. **设备清单**：地图右上角「设备清单」按钮打开弹窗，不影响地图尺寸。
5. **设备图标与弹窗**：点击单个设备图标或聚类数字，打开**设备缩略列表**（仅含可查看详情的设备类型：接口、驱动器、CPU、总线、箱子、安全终端、等级维持器、控制器、IO 端口、量子桥、能源元件、P2P 等；终端/监视器/发射器/样板供应器不显示）。列表中点击一行打开右侧**详情抽屉**；聚类打开时地图会临时放大 1.5×，关闭弹窗后还原。平移/缩放地图不会自动关闭弹窗；弹窗内滚轮仅滚动列表。**悬停聚类数字**时显示各设备类型图标及数量（xN）。
6. **左侧 AE 图例窗**：地图左侧常驻窄色条；鼠标移入展开，可勾选类别可见性、点击色块改色（同时影响 AE 透视层与设备图标描边）；**取消勾选后图例项仍保留**（变暗显示），仅隐藏地图上对应设备图标；锁定后只读。原工具栏「AE 着色」按钮已移除。
7. **本地缓存**：浏览器会缓存已下载瓦片（IndexedDB）；换设备登录 MC 后客户端也会同步快照到 `TeXTech/WebAE/map-cache/`。
8. **AE 透视层**：与地形同时采集；**透明度**滑条（拓扑设置）仅影响 AE 设备着色像素（不影响地形）。
9. **滚轮**：在世界地图、树形拓扑与线缆模拟视图中滚轮用于缩放，不会滚动整页。
10. **配置**：`worldMapSnapshotMode`、`worldMapJourneyMapEnabled`、`worldMapConsentRadiusChunks`、`worldMapOwnerSkipConsent` 等，详见 [开发者手册 §11.26](开发者手册.md#1126-世界地图视图客户端快照--journeymap)。

### 监视器绑定与预览

侧栏「监视器绑定」只读展示各数据监视器的图表槽位与 GT 绑定坐标。点击槽位「预览」可在 Drawer 中查看与游戏内监视器一致的折线历史（只读，编辑仍在游戏内）。

### 自动化告警

`TeXTech/WebAE/web-alerts.json` 驱动库存阈值、CPU 卡住、GT 异常、下单完成与频道超载检测。浏览器除 10 秒轮询外，还通过 SSE（`/api/events/stream`）实时推送新告警；标签页隐藏时暂停连接。

### 移动端与 PWA

内置 `manifest.webmanifest`，窄屏下自动调整侧栏与表格布局。可将控制台「添加到主屏幕」以便手机查看存储/GT/拓扑（仍建议通过 SSH 隧道访问，勿直接暴露公网）。

### 仪表盘、聊天与设置

- **仪表盘**：GridStack 拖拽布局，24 套主题 + 5 种布局预设，设置侧滑面板可调整全局间距/颜色/图表。
- **聊天**：侧栏 💬 进入；网页消息以 `[Web] <玩家名>: 内容` 广播到游戏内。
- **导航栏**：边缘按钮循环展开 → 折叠 → 隐藏三态。
- **顶栏**：连接点旁显示刷新倒计时/状态。

## 6. 注意事项

- **默认仅本机访问**：`bindAddress=127.0.0.1` 确保只有本机浏览器能访问
- **局域网访问风险**：改 `0.0.0.0` 后局域网内持有 Token 的设备均可访问，请配合防火墙或 SSH 隧道
- **强制认证**：所有 `/api/` 端点都需要 Token；强制刷新等管理员操作额外要求 OP
- **Token 安全**：Token 可查看存储并提交合成，请妥善保管
- **配方搜索需先上传**：OP 执行 `/admweb recipes upload` 触发客户端 NEI 采集上传
- **图标上传**：OP 执行 `/admweb icons upload [packName]`；首次加载网页会自动选择服务端记录的最近 pack
- **reload 限制**：`/admweb reload` 不重载 web 服务器监听参数；Token 与运行时数据文件不受影响
