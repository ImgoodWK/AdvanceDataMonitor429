# TeXTech GitHub Wiki navigation source

The Markdown files in this directory are the version-controlled source for the repository's navigation-only GitHub Wiki. A dedicated workflow publishes them to the Wiki repository.

`docs/` and machine-readable project data remain canonical. Wiki pages must stay short, declare that boundary at the top, and link to both Chinese and English source documents rather than copying technical content.

Published pages: `Home`, `Getting Started`, `Features`, `WebAE`, `AI and Voice`, `Development`, `Project History`, `Security and Provenance`, and `_Sidebar`.
